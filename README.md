PSBT decode shell — local vault, no broadcast.

## Features

- BTC path m/84'/0'/0'
- Local derive + address codec
- C++20, CMake, no third-party fetch

## Prerequisites

- CMake 3.20+
- A C++20 compiler
- Git

## Getting Started

```bash
git clone <repo-url>
cd psbt-decode
cmake -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## Project Structure

```
include/psbt-decode/wallet.h
src/wallet.cpp

```
